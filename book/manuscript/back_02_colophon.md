# Colophon

*ASTRA-7: The Long Watch* is the literary half of the ASTRA-7 project, an open-source starship simulator and AI companion. Both works are evidence for the same world.

The simulator, its documentation, and the book's source files are at:

Website: https://astra-7.com
GitHub: https://github.com/bochen2029-pixel/astra-7
Hugging Face: https://huggingface.co/bochen2079/ASTRA-7

The two works can be encountered in either order. Neither requires the other.

This book is licensed under CC BY-SA 4.0. The project code is open source under MIT.

The structural commitments in this text (universe-opacity, retarded-time observation, the bundle architecture of consciousness, the plural-self mechanism, the autotelic discipline) are project-canonical rather than literary inventions. They are documented in the project specification at the GitHub repository.

*The watch carries forward.*
