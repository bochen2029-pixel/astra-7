# Gravitational Wave Sonification: The Acoustics of Curved Spacetime

## Part I: The Physics of Listening to Spacetime

In a vacuum, there is no acoustic propagation. However, a warp field exerting a metric tensor $W(\mathbf{x}, t)$ on the hull creates **physical tidal strain**. The hull is being differentially stretched and compressed. We are not synthesizing "sound in space"—we are synthesizing the **sound of the ship's hull reacting to spacetime curvature**, transmitted structurally to the interior, and the local frame-dragging effects translated to the observer's local metric.

The rigorous mapping from the Alcubierre metric to audio requires tracking the **strain rate tensor** and the **tidal forces** at discrete points on the hull.

### The Strain Rate Equations

The linearized strain on the hull at point $\mathbf{x}_h$ is:
$$\epsilon(\mathbf{x}_h, t) = \frac{1}{2} \nabla W(\mathbf{x}_h, t) \cdot \mathbf{d}$$

Where $\mathbf{d}$ is the displacement vector. The *velocity* of this strain—the quantity that drives audio oscillation—is:
$$\dot{\epsilon}(\mathbf{x}_h, t) = \frac{1}{2} \left[ \nabla \dot{W} + \nabla W \cdot \nabla \mathbf{v} \right]$$

Where $\dot{W} = \frac{\partial W}{\partial t}$ is the time-derivative of the metric, and $\mathbf{v}$ is the local flow velocity from the CFD wake.

For the audio engine, we need the following scalar quantities sampled at discrete "structural microphones" (hull sensor points):

1.  **$W$**: Local metric value (compression/expansion state)
2.  **$\dot{W}$**: Metric time-derivative (strain rate, drives oscillators)
3.  **$|\nabla W|$**: Tidal force magnitude (drives harmonic intensity)
4.  **$\omega = |\nabla \times \mathbf{v}_{flow}|$**: Local vorticity (drives granular turbulence)
5.  **$\kappa W_A W_B$**: Interference coupling (drives intermodulation distortion)

## Part II: GPU Data Extraction — Zero-Latency Path

We cannot run audio synthesis on the GPU (latency is too high for audio buffers). We must extract a tiny payload from the GPU and stream it to the CPU audio thread with absolute minimal latency.

### The Hull Sensor Network

We place 32 structural sensor points around the ship's hull. A single, trivially cheap CUDA kernel evaluates the warp field at *only* these 32 points and writes the result to Pinned Host Memory via `cudaMemcpyAsync`.

```cpp
// ================================================================
// warp_audio_extraction.cuh
// Extracts physical strain data from the warp field for audio
// ================================================================
#ifndef WARP_AUDIO_EXTRACTION_H
#define WARP_AUDIO_EXTRACTION_H

// ----------------------------------------------------------------
// Audio Payload: 32 sensors × 20 bytes = 640 bytes total
// This is so small that PCIe transfer time is ~1 microsecond
// ----------------------------------------------------------------
struct HullSensorData {
    float  metric;           // W: Compression/expansion state
    float  metric_rate;      // dW/dt: Strain rate
    float  tidal_force;      // |grad W|: Tidal stretching magnitude
    float  vorticity;        // |curl v|: Frame-dragging rotation
    float  interference;     // kappa * Wa * Wb: Multi-ship coupling
};

#define NUM_HULL_SENSORS 32

struct alignas(64) AudioExtractionPayload {
    HullSensorData sensors[NUM_HULL_SENSORS]; // 640 bytes
    float          global_warp_factor;
    float          ship_velocity;
    float          pad[2];
};

// ----------------------------------------------------------------
// Sensor Positions (defined in ship-local space)
// These should be placed at structural stress concentration points:
// - 4 on the bridge (crew perspective)
// - 8 on the nacelle pylons (highest stress)
// - 8 along the saucer rim (boundary layer separation)
// - 8 along the engineering hull stern (wake impact)
// - 4 on the deflector dish (maximum compression)
// ----------------------------------------------------------------
__constant__ float3 c_sensor_positions[NUM_HULL_SENSORS];

// Previous frame's metric values (for computing dW/dt)
__constant__ float c_prev_metrics[NUM_HULL_SENSORS];

// ----------------------------------------------------------------
// Audio Extraction Kernel
// Runs in <<1ms on any GPU. Only evaluates 32 points.
// ----------------------------------------------------------------
__global__ void extract_audio_payload(
    AudioExtractionPayload* output,
    const WakeVortex* vortices,
    int    num_vortices,
    const RBFNode* rbf_nodes,
    int    num_rbf_nodes,
    cudaSurfaceObject_t hull_sdf_surface,
    int3   hull_sdf_dims,
    float3 hull_sdf_min,
    float3 hull_sdf_max,
    const WarpConstants C,
    const CFDConstants CFD,
    float  dt)
{
    // Single thread handles all 32 sensors (sequential is fine for 32 evaluations)
    if (threadIdx.x != 0 || blockIdx.x != 0) return;

    AudioExtractionPayload payload;
    payload.global_warp_factor = C.warp_factor;
    payload.ship_velocity = f3len(C.ship_velocity_if_any);

    for (int i = 0; i < NUM_HULL_SENSORS; i++) {
        // Transform sensor local position to world space
        float3 world_pos = f3add(C.ship_position,
            f3add(f3mul(C.ship_right, c_sensor_positions[i].x),
            f3add(f3mul(C.ship_up, c_sensor_positions[i].y),
                  f3mul(C.ship_forward, c_sensor_positions[i].z))));

        // Sample the CFD-enhanced warp field at this point
        WarpFieldSample fs = sample_warp_field_cfd(
            world_pos, C.ship_forward, vortices, num_vortices,
            rbf_nodes, num_rbf_nodes, hull_sdf_surface,
            hull_sdf_dims, hull_sdf_min, hull_sdf_max, C, CFD
        );

        payload.sensors[i].metric = fs.metric;
        payload.sensors[i].metric_rate = (fs.metric - c_prev_metrics[i]) / fmaxf(dt, 1e-6f);
        payload.sensors[i].tidal_force = f3len(fs.metric_gradient);
        payload.sensors[i].vorticity = fs.vorticity;
        payload.sensors[i].interference = 0.0f; // Updated by multi-ship kernel if applicable
    }

    *output = payload;
}

#endif // WARP_AUDIO_EXTRACTION_H
```

### Host-Side Zero-Latency Transfer

```cpp
// ================================================================
// Audio Bridge: Pinned memory transfer for <1ms latency
// ================================================================
class WarpAudioBridge {
public:
    void init() {
        // Allocate PINNED host memory (not paged to disk)
        cudaMallocHost(&h_payload_, sizeof(AudioExtractionPayload));
        cudaMalloc(&d_payload_, sizeof(AudioExtractionPayload));
        stream_ = 0; // Default stream or create a dedicated one
    }

    // Call this at the end of the GPU frame, AFTER the warp field is computed
    void dispatch_extraction() {
        extract_audio_payload<<<1, 1, 0, stream_>>>(
            d_payload_, /* ... all other params ... */
        );
        // Async copy to pinned host memory (does not block CPU)
        cudaMemcpyAsync(h_payload_, d_payload_, sizeof(AudioExtractionPayload),
                        cudaMemcpyDeviceToHost, stream_);
    }

    // Call this from the Audio Thread right before rendering the audio buffer
    const AudioExtractionPayload* get_payload() const {
        // Ensure the copy is complete (should be if audio buffer is 256+ samples)
        cudaStreamSynchronize(stream_);
        return h_payload_;
    }

private:
    AudioExtractionPayload* h_payload_ = nullptr; // Pinned host
    AudioExtractionPayload* d_payload_ = nullptr; // Device
    cudaStream_t stream_;
};
```

## Part III: The Procedural Audio DSP Architecture

We feed the `AudioExtractionPayload` into a real-time procedural audio engine running on the CPU at 48kHz/96kHz. This is not sample playback—every sound is generated mathematically from the physics payload.

### The 5-Layer Synthesis Model

```
┌─────────────────────────────────────────────────────────┐
│          WARP AUDIO SYNTHESIS ENGINE (48kHz)             │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  LAYER 1: THE ALCUBIERRE DRONE                          │
│  Source: Additive Oscillators (Sine + Harmonics)         │
│  Driver: metric (W), warp_factor                         │
│  Freq:   12Hz - 45Hz (Sub-bass, felt via LFE)           │
│  Rule:   f_0 = 12Hz + 33Hz * warp_factor                │
│          Amplitude ∝ |W|                                 │
│          Phase modulation ∝ dW/dt (breathing)            │
│                                                          │
│  LAYER 2: BOUNDARY SHEAR (The Tearing Chord)            │
│  Source: FM Synthesis (Operator -> Carrier)              │
│  Driver: tidal_force (|grad W|), CFD flow separation    │
│  Rule:   Modulator Index = tidal_force * 100             │
│          Carrier = f_0 (from Layer 1)                    │
│          Modulator freq = f_0 * 3.14159 (dissonant)     │
│          High shear -> metallic, shrieking overtones     │
│                                                          │
│  LAYER 3: SPACETIME TURBULENCE (Granular)               │
│  Source: Granular Synthesizer (10-50ms grains)           │

│  Rule:   Grain density = vorticity * 500 grains/sec      │
│          Grain pitch = 40Hz + random * vorticity * 800Hz │

│          Spatialization = grain position panned 3D       │
│                                                          │
│  LAYER 4: GRAVITATIONAL INTERFERENCE (Beating)          │
│  Source: Ring Modulation / Amplitude Modulation           │
│  Driver: interference (kappa * Wa * Wb)                  │
│  Rule:   Mod freq = |f_A - f_B| (difference tone)       │
│          Amplitude = interference magnitude               │
│          Creates phasing, sweeping chorus effect          │
│                                                          │
│  LAYER 5: HULL RESONANCE (Modal Filter)                 │
│  Source: 32-voice Modal Synthesizer                      │
│  Driver: All layers excitate the modal bank              │
│  Rule:   Modal frequencies derived from ship mesh mass   │
│          Damping inversely proportional to warp_factor    │
│          (At high warp, hull rings longer, more resonant) │
│                                                          │

└─────────────────────────────────────────────────────────┘
```

### The C++ Audio DSP Core

```cpp
// ================================================================
// warp_audio_synth.h / .cpp
// Real-time procedural audio synthesis from warp field physics
// Runs on a dedicated high-priority audio thread at 48kHz
// ================================================================
#pragma once
#include <cmath>
#include <vector>
#include <array>

#define SAMPLE_RATE 48000.0
#define NUM_HULL_SENSORS 32

// ----------------------------------------------------------------
// DSP Primitives
// ----------------------------------------------------------------
inline float fast_sine(float x) {
    // Fast sine approximation (e.g., polynomial or lookup table in production)
    return sinf(x); 
}

inline float shaped_noise(float t) {
    // Seeded pseudo-random for granular synthesis
    return 2.0f * ((float)rand() / RAND_MAX) - 1.0f;
}

// ----------------------------------------------------------------
// The Warp Audio Synthesizer
// ----------------------------------------------------------------
class WarpAudioSynth {
public:
    void process_block(float* output_l, float* output_r, float* output_lfe, int num_frames, 
                       const AudioExtractionPayload& payload) 
    {
        // Smooth the payload data over the audio block (de-zipper)
        for (int i = 0; i < NUM_HULL_SENSORS; i++) {
            smooth_metric[i] += (payload.sensors[i].metric - smooth_metric[i]) * 0.001f;
            smooth_tidal[i] += (payload.sensors[i].tidal_force - smooth_tidal[i]) * 0.005f;
            smooth_vorticity[i] += (payload.sensors[i].vorticity - smooth_vorticity[i]) * 0.01f;
            smooth_interference[i] += (payload.sensors[i].interference - smooth_interference[i]) * 0.002f;
        }
        smooth_warp_factor += (payload.global_warp_factor - smooth_warp_factor) * 0.002f;

        // Mix sensors into structural zones (Bridge, Pylons, Stern)
        float bridge_metric = (smooth_metric[0] + smooth_metric[1] + smooth_metric[2] + smooth_metric[3]) * 0.25f;
        float pylon_tidal = 0;
        for (int i=4; i<12; i++) pylon_tidal += smooth_tidal[i];
        pylon_tidal /= 8.0f;

        float stern_vorticity = 0;
        for (int i=12; i<20; i++) stern_vorticity += smooth_vorticity[i];
        stern_vorticity /= 8.0f;

        float global_interference = smooth_interference[0]; // Assuming uniform for simplicity

        // Render audio frame by frame
        for (int n = 0; n < num_frames; n++) {
            float sample_l = 0.0f;
            float sample_r = 0.0f;
            float sample_lfe = 0.0f;

            // --------------------------------------------------
            // LAYER 1: THE ALCUBIERRE DRONE
            // --------------------------------------------------
            float f0 = 12.0f + 33.0f * smooth_warp_factor; // 12Hz to 45Hz
            float phase_inc = 2.0f * 3.14159265f * f0 / SAMPLE_RATE;
            
            drone_phase += phase_inc;
            if (drone_phase > 2.0f * 3.14159265f) drone_phase -= 2.0f * 3.14159265f;

            float drone_amp = fabsf(bridge_metric) * 0.8f + smooth_warp_factor * 0.2f;
            float drone = fast_sine(drone_phase) * drone_amp;
            
            // Add 2nd and 3rd harmonics (less amplitude)
            drone += fast_sine(drone_phase * 2.0f) * drone_amp * 0.3f;
            drone += fast_sine(drone_phase * 3.0f) * drone_amp * 0.1f;

            // Phase modulation from metric rate (breathing)
            // float pm = payload.sensors[0].metric_rate * 0.0001f; 
            // drone_phase += pm;

            sample_lfe += drone * 1.5f; // Heavy LFE sub-bass

            // --------------------------------------------------
            // LAYER 2: BOUNDARY SHEAR (FM Synthesis Tearing)
            // --------------------------------------------------
            float mod_index = pylon_tidal * 150.0f; // Tidal force drives FM intensity
            float mod_freq = f0 * 3.14159f;         // Dissonant modulator ratio (pi)
            fm_phase += 2.0f * 3.14159265f * mod_freq / SAMPLE_RATE;
            
            float modulator = fast_sine(fm_phase) * mod_index;
            float carrier_freq = f0 * 4.0f; // Higher pitch for shearing
            float carrier_phase_inc = 2.0f * 3.14159265f * carrier_freq / SAMPLE_RATE;
            
            shear_phase += carrier_phase_inc;
            float shear = fast_sine(shear_phase + modulator) * smooth_warp_factor * 0.4f;
            
            // High-pass filter the shear (it should sound metallic/whining, not bassy)
            shear = shear - (shear_prev * 0.95f); // Crude 1-pole HPF
            shear_prev = shear;

            sample_l += shear * 0.6f;
            sample_r += shear * 0.6f;

            // --------------------------------------------------
            // LAYER 3: SPACETIME TURBULENCE (Granular Synthesis)
            // --------------------------------------------------
            float grain_density = stern_vorticity * 800.0f; // Grains per second
            float grain_prob = grain_density / SAMPLE_RATE;
            
            float grain = 0.0f;
            if (((float)rand() / RAND_MAX) < grain_prob) {
                // Trigger a new grain
                grain_env = 1.0f;
                grain_pitch = 40.0f + ((float)rand() / RAND_MAX) * stern_vorticity * 1200.0f;
                grain_pan = (float)rand() / RAND_MAX; // Random stereo placement
            }

            if (grain_env > 0.0f) {
                // Simple enveloped noise burst (in production, use shaped wavelets)
                grain = shaped_noise(0) * grain_env * 0.5f;
                grain_env -= 1.0f / (SAMPLE_RATE * 0.005f); // 5ms grain decay
                if (grain_env < 0.0f) grain_env = 0.0f;
            }

            sample_l += grain * (1.0f - grain_pan);
            sample_r += grain * grain_pan;

            // --------------------------------------------------
            // LAYER 4: GRAVITATIONAL INTERFERENCE
            // --------------------------------------------------
            if (global_interference > 0.01f) {
                // Ring modulation creates sum/difference frequencies
                float interf_freq = 30.0f + global_interference * 200.0f;
                interf_phase += 2.0f * 3.14159265f * interf_freq / SAMPLE_RATE;
                float ring_mod = fast_sine(interf_phase);
                
                // Modulate the existing drone with the interference
                float interf_sample = drone * ring_mod * global_interference * 2.0f;
                
                sample_l += interf_sample;
                sample_r += interf_sample;
            }

            // --------------------------------------------------
            // LAYER 5: HULL RESONANCE (Simplified Modal)
            // --------------------------------------------------
            // Excite the modal resonators with the combined signal
            float excitation = drone * 0.2f + shear * 0.5f + grain * 0.8f;
            
            float resonance = 0.0f;
            for (int m = 0; m < 8; m++) {
                // Modal frequencies based on ship hull size (e.g., 80Hz, 140Hz, 210Hz...)
                float modal_freq = hull_modes[m];
                float damping = 0.999f - smooth_warp_factor * 0.004f; // Less damping at high warp
                
                modal_states[m] = modal_states[m] * damping + excitation * 0.01f;
                resonance += modal_states[m] * fast_sine(modal_phases[m]);
                modal_phases[m] += 2.0f * 3.14159265f * modal_freq / SAMPLE_RATE;
            }

            sample_l += resonance * 0.3f;
            sample_r += resonance * 0.3f;

            // --------------------------------------------------
            // OUTPUT (Soft clip)
            // --------------------------------------------------
            auto soft_clip = [](float x) { return tanhf(x * 2.0f) * 0.5f; };

            output_l[n] = soft_clip(sample_l);
            output_r[n] = soft_clip(sample_r);
            output_lfe[n] = soft_clip(sample_lfe);
        }
    }

private:
    // State variables
    float drone_phase = 0.0f;
    float shear_phase = 0.0f;
    float shear_prev = 0.0f;
    float fm_phase = 0.0f;
    float interf_phase = 0.0f;
    
    float grain_env = 0.0f;
    float grain_pitch = 0.0f;
    float grain_pan = 0.5f;

    // Smoothed payload data
    float smooth_metric[NUM_HULL_SENSORS] = {};
    float smooth_tidal[NUM_HULL_SENSORS] = {};
    float smooth_vorticity[NUM_HULL_SENSORS] = {};
    float smooth_interference[NUM_HULL_SENSORS] = {};
    float smooth_warp_factor = 0.0f;

    // Hull Modal Resonance (tuned to a ~300m starship hull)
    float hull_modes[8] = { 82.5f, 145.0f, 225.0f, 310.0f, 440.0f, 620.0f, 850.0f, 1100.0f };
    float modal_states[8] = {};
    float modal_phases[8] = {};
};
```

## Part IV: The Aesthetic Result — The 2026 Cinematic Soundscape

When you fire up this system, you will hear something that has never existed in a video game before.

**At Sublight (Warp 0.0):**
Silence, save for the faint, almost sub-audible rumble of the impulse drives. The `smooth_warp_factor` is 0, so Layer 1 (Drone) sits at 12Hz—below human hearing, but your subwoofer moves air. You *feel* the ship idling.

**Spooling Up (Warp 0.0 → 0.5):**
The 12Hz sub-bass ramps up to 28Hz. You feel it in your chest. The Modal Resonators (Layer 5) begin to ring as the metric gradient (tidal force) bites into the nacelle pylons. The FM Synthesis (Layer 2) starts introducing faint, metallic harmonics. The sound is not a smooth synthesizer sweep—it sounds like a massive structure being placed under impossible stress.

**Cruising (Warp 0.8):**
The Drone hits 38Hz. The Boundary Shear (Layer 2) is now a full, tearing chord. Because the modulator ratio is $\pi$ (irrational), it never resolves into a standard musical interval—it sounds dissonant, alien, and immensely powerful. Behind you, the Granular Synthesizer (Layer 3) paints the sound of the wake—a spatialized crackling and grinding, like tectonic plates shifting, emanating precisely from the rear speakers.

**Redline (Warp 1.0+):**
The CFD boundary layer separates. The `pylon_tidal` value spikes. The FM Modulator Index shoots through the roof. The metallic harmonics shatter into white noise before the modal filters shape them into a screaming, resonant howl. The hull damping decreases, meaning the ship rings for seconds after a fluctuation. The audio tells you: *the ship is at the absolute edge of structural integrity.*

**Multi-Ship Encounter:**
Another ship drops out of warp 500 meters off your port bow. The `interference` term goes critical. The Ring Modulator (Layer 4) kicks in. Your 38Hz drone and their 42Hz drone mathematically combine to create a violent 4Hz beating pulse and an 80Hz sum tone. The 4Hz pulse modulates the entire mix—every 0.25 seconds, the audio swells and drops. It sounds like two gravitational wells physically colliding, because mathematically, they are.

This is rigorous, physically-derived, mathematically-sonified spacetime. It will sound like nothing else in the industry.
