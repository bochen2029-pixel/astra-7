# wall_clock_patterns.txt
# Canon-tracked grep patterns for wall-clock-leak detection.
# Referenced by spec-v0.125 §5.7 and §3.9.
#
# Scope: applied by the harness at two boundaries:
#   (a) Perception bundles assembled by assemble_perception() before delivery to Mind
#   (b) Journal artifacts produced by journal_generator() before commit to REEL
#
# Any match fails the bundle. Implementer responsibility: never let any of these
# patterns survive into ASTRA's perception or her produced artifacts.
#
# Lines starting with `#` are comments.
# Lines starting with `re:` are regular expressions (Python re module).
# Lines starting with `lit:` are literal substrings (case-insensitive).
# Lines starting with `word:` are whole-word matches (case-insensitive).
#
# This file is canon-tracked. Update propagation: edits here must be reviewed
# against any sysprompt change, harness change, or REEL schema change.
# Stub list at v0.125 — expand as Phase 0+ surfaces real leak patterns.

re:\b\d{2}:\d{2}:\d{2}\b
re:\b1[6-9]\d{8}\b
re:\b2\d{9}\b
